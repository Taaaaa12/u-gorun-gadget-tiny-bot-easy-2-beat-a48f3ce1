A tiny long-only paper-trading bot for hourly Solana bars that beats buy-and-hold by buying MACD-confirmed dips (MACD above its signal with CCI at or under -48) and by keeping a small fast scalp sleeve so the entry always clears the 8-trade guardrail, even in a quiet window.

## Run it

```sh
node main.ts
```
